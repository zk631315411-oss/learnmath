# PV 真实性证据与产品实录

本目录保存 PV 制作中的真实账号状态、实机录屏、探针记录和数据库快照，与 `artifacts/pv/` 中的剪辑素材分开管理。

## 正式证据

| 路径 | 内容 |
|---|---|
| `ACCOUNT_MANIFEST.md` | 非敏感账号身份与录制规则 |
| `formal-recording/` | 正式账号四轮对话录屏、页面文本与录制后状态 |
| `formal-map/prestate/` | 正式账号地图前态 |
| `formal-map/poststate/` | 正式账号地图后态 |
| `v3-browser-assets/` | V3 证据段、首页状态和 KG 卡片补录素材 |
| `v3-formal-map-post/` | V3 正式后态地图补录 |
| `snapshots/` | 正式录制前态及 S1b 回滚快照 |
| `REPORT.md` | 真实性核验和录制过程总记录 |

## 过程记录

`probe-turn*`、根目录 `q1*`/`q2*`、早期地图截图及录制脚本属于试拍和排障记录。它们保留原路径，避免破坏报告中的证据引用，不应冒充正式账号素材。

## 凭据边界

本目录不保存明文密码或 JWT。正式账号的缓存令牌属于本机临时凭据，不是交付素材，也不得进入 Git、截图或视频。
