# 学生视角移动端体验修订验收记录

> 验收日期：2026-08-26  
> 分支：`feature/internal-test-welcome`  
> 范围：移动端截图提问、提问记录面板和记录删除；桌面端删除交互不在本轮范围。

## 本轮变更

- 框选流程按设备显示文案：桌面端使用“拖动鼠标框选区域，按 ESC 取消”，手机裁剪页使用“拖动手指调整截图区域”。截图准备期间显示加载态，只有真正失败才显示错误态。
- 移动端工具栏和面板统一命名为“提问记录”；学习地图仍从 Header 入口进入。
- 空记录显示设备对应的第一步行动指引，保留原快捷问题入口。
- 手机端记录支持水平左滑露出删除按钮，阈值为 48px、最大露出 88px；垂直滚动不触发删除，未达阈值会回弹。
- 已登录用户删除前二次确认；匿名用户显示登录/注册选择；生成中的记录禁删；删除失败保留记录并提供重试。
- 删除聊天只调用现有聊天删除接口，不删除 evidence、学习进度或学生模型数据。
- 缩放持久化和“恢复适宽”行为保持不变；桌面阅读布局、地图入口和桌面删除实现未改动。
