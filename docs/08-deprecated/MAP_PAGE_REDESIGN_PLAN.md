# LearnMath 地图页改版计划

> 日期：2026-08-18  
> 范围：仅修改地图模式及其章节详情，不改问答、SSE、evidence 和 learning-map API。  
> 本文补充并覆盖同目录 `FRONTEND_REDESIGN_PLAN.md` 中与地图首页展示和章节卡点击行为有关的要求。

## 1. 改版目标

地图页要回答三个问题：当前是哪本教材、学到了哪里、下一步做什么。

本轮改版完成后：

1. 用户可在地图页直接选择教材，切换入口始终可见、可用。
2. 章节卡不再重复显示章节编号，并能清楚表达未开始、学习中、需巩固和已掌握状态。
3. 地图页不再只是章节目录；点击章节卡先看章节知识节点，点击明确的学习动作才进入 PDF。
4. 首屏先显示页面结构和章节，再渐进补齐知识节点，不因单章请求变慢而整页等待。
5. 空状态、失败状态和移动端都保持紧凑、可操作。

## 2. 当前问题

| 优先级 | 问题 | 当前表现 | 修改方向 |
|---|---|---|---|
| P1 | 地图页不能选择教材 | 当前教材只是静态标题，用户无法发现切换入口 | 在地图标题区加入教材选择器 |
| P1 | 页面不像学习地图 | 章节卡只有名称、空进度条和知识点总数 | 加入状态摘要，并提供章节节点详情 |
| P1 | 章节卡行为含混 | 点击卡片直接进入 PDF，无法先查看本章知识结构 | 卡片进入章节详情；独立按钮进入阅读 |
| P1 | 章节编号重复 | 同时显示“第 1 章”和“第1章 线性方程组的解法” | 解析章节编号与标题，只显示一次 |
| P2 | 零进度表达机械 | `0 / 443 已探索` 数字大、信息弱 | 改为“尚未开始 · 443 个知识点” |
| P2 | 所有卡片视觉相同 | 无法快速分辨学习中、需巩固、已掌握 | 使用状态点、分段进度条和状态摘要 |
| P2 | 无复习内容时留白过大 | “目前没有待复习内容”单独占据大区块 | 压缩为空状态行，有内容时再展开列表 |
| P2 | 刷新入口语义弱 | 图标远离当前教材，切换与刷新关系不清楚 | 放入地图标题工具区并保留 tooltip |

## 3. 页面结构

### 3.1 桌面端

```text
┌──────────────────────────────────────────────────────────────┐
│ 继续学习                                                     │
│ 第 2 章 · 矩阵的秩                         [继续学习]          │
└──────────────────────────────────────────────────────────────┘

学习地图
[ 高等代数（上册）丘维声  ▾ ]                    [刷新]
6 章 · 1514 个知识点 · 12 个已有学习记录

┌──────────────┐ ┌──────────────┐ ┌──────────────┐
│ 第 1 章       │ │ 第 2 章       │ │ 第 3 章       │
│ 线性方程组…   │ │ 行列式         │ │ 解集的结构     │
│ ● 学习中      │ │ ○ 尚未开始     │ │ ! 需要巩固     │
│ [状态分段条]  │ │ [状态分段条]  │ │ [状态分段条]  │
│ 12/112 已探索 │ │ 273 个知识点   │ │ 3 个待巩固     │
│ 查看地图   →  │ │ 查看地图   →  │ │ 查看地图   →  │
└──────────────┘ └──────────────┘ └──────────────┘

需要巩固（仅在有内容时展开）
知识点名称 · 所属章节 · 来源提问                         [复习]
```

### 3.2 章节详情

点击章节卡后留在地图模式，页面切换为章节详情：

```text
[← 全部章节]  第 2 章 · 行列式                       [开始本章]
学习中 4 · 需要巩固 2 · 已掌握 8

2.1 行列式的定义
  ● 二阶与三阶行列式             学习中          [继续]
  ○ n 阶行列式                   未探索          [开始]

2.2 行列式的性质
  ! 行列式按行展开               需要巩固        [复习]
```

第一版继续采用“分节 + 节点列表”，不新造图布局。节点间关系数据不足时，不用连线伪装成关系图。后续如 API 提供稳定的前置关系，再升级为可视化节点图。

## 4. 交互定案

### 4.1 教材选择

- 地图标题本身改为教材选择按钮，显示当前教材全名和向下箭头。
- 点击后打开菜单，列出 `TEXTBOOKS` 中全部教材；当前教材显示勾选状态。
- 切换时调用现有 `setTextbookId`，不新增第二套教材状态。
- 切换后立即更新标题，章节区域显示新教材骨架或 session 缓存；旧教材内容不得短暂冒充新教材。
- 每本教材继续使用独立的 `learnmath.workspace.<textbookId>` 阅读页码和视图记录。
- 地图请求进行中，教材选择器保持可用。仅 CaptureBubble 正在流式回答时沿用现有切书锁定规则。
- 请求失败只在章节区显示错误；教材菜单和“直接开始阅读”仍可操作。
- 首次没有持久化选择时沿用当前默认教材，但选择入口必须显示。

### 4.2 章节标题

新增纯前端格式化 helper，将 API 的章节字符串拆成编号和标题：

```text
输入：第1章 线性方程组的解法
编号：第 1 章
标题：线性方程组的解法
```

- 支持 `第1章`、`第 1 章`、`1.` 等常见前缀。
- 无法解析时直接使用原字符串，不丢内容。
- 格式化仅用于显示，不修改 API 参数；请求 `/nodes?chapter=` 时仍传原始章节字符串。

### 4.3 章节卡

- 卡片主点击区进入章节详情，不直接跳 PDF。
- 卡片右下使用“查看地图 + 箭头”表达去向，不只放一个无说明的 Chevron。
- 章节详情顶部提供“开始本章”按钮，继续使用现有 section-page 扫描落页逻辑。
- 卡片状态从 `status_counts` 和 `exploration_progress` 计算：
  - `explored = 0`：尚未开始。
  - `needs_review > 0`：需要巩固，优先级最高。
  - `learning + basically_mastered > 0`：学习中。
  - 全部为 `mastered`：已掌握。
- 进度条使用分段颜色：未探索为浅灰、学习中为琥珀、基本掌握为浅绿、已掌握为深绿、需巩固为玫红。
- 颜色之外必须同时有文字或图标，不依赖颜色表达状态。

### 4.4 继续学习

- 有 `needs_review` 节点时优先显示该节点，并将动作写为“开始复习”。
- 否则显示第一个 `learning` 节点，动作写为“继续学习”。
- 没有学习记录时显示“从教材第一页开始”，动作写为“打开教材”。
- 来源提问存在时保留“来源提问”次级动作。
- 继续学习卡直接进入阅读模式，不经过章节详情。

### 4.5 需要巩固

- 有待巩固节点时显示最多 6 条，保留节点名称、所属章节和复习动作。
- 没有内容时不渲染完整列表容器，只在章节网格下方显示一行轻量状态。
- 点击复习优先回到来源提问页；来源已删除时使用该节 section-page 落页。

## 5. 加载与性能

- `GET /learning-map/chapters` 只请求一次，地图首页和侧栏共用 `useMapHomeData`。
- 章节接口返回后立即渲染真实章节卡，不等待所有 `/nodes` 请求完成。
- 各章节点并行请求，单章完成即更新该章；单章失败只影响该章。
- 节点未返回时卡片显示章节接口已有的进度和总数，并标记“详情准备中”，不显示整页骨架。
- session 缓存按教材隔离；切回已加载教材时先显示缓存，再按现有刷新策略更新。
- 新 evidence 落库后在后台刷新地图，不遮挡当前页面。
- 当前本地环境验收目标：页面框架立即出现，章节卡在 1.5 秒内出现；节点详情渐进完成。

## 6. 视觉规范

- 地图页最大内容宽度沿用 `max-w-6xl`，桌面三列、平板两列、移动端单列。
- 继续学习卡降低高度，突出一个主动作，不扩大成营销式 Hero。
- 章节卡统一稳定高度；加载文案、状态标签和 hover 不得改变卡片尺寸。
- 主色继续使用 indigo；状态使用 amber、emerald、rose 和 slate，避免整页只有蓝紫色。
- 卡片圆角使用现有 12/16px 体系，不增加更大的胶囊形容器。
- 正文和元数据达到可读对比度；截图中偏浅的进度数字需加深一级。
- 刷新、返回、来源提问等图标按钮保留 tooltip 和 `aria-label`。

## 7. 响应式要求

### 桌面（≥1024px）

- 教材选择器与刷新按钮同一行。
- 章节网格三列；1280px 下不得挤压标题或状态。
- 章节详情使用完整内容宽度，不塞入窄侧栏。

### 平板（768–1023px）

- 章节网格两列。
- 继续学习卡允许动作区换行，但不与标题重叠。

### 移动端（<768px）

- 教材选择器占可用宽度，菜单使用底部 sheet 或等价的全宽菜单。
- 继续学习卡纵向排列，主按钮宽度为 100%。
- 章节卡单列，点击目标高度不小于 44px。
- 章节详情的状态摘要可换行，节点操作保持可点击且不溢出。
