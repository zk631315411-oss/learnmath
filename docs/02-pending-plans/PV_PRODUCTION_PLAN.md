### 3.4 Manim 动画（1:08-1:30，含过场）——关键路径

**动作链（固定，不得拆开或换用其他排列 / 其他阶数）**：行号 `123` → 交换成 `213` → 高亮逆序对 `(2,1)` → `τ = 1` → 3×3 矩阵 `[[1,2,3],[0,1,4],[0,0,1]]` 交换第 1、2 行 → `det(A') = -det(A)`（A 为上三角，`det(A) = 1`，对角线乘积一眼可算）。

**触发方式（v8 执行口径）**：动画由对话内真实触发。学生第四轮主请求逐字保留：“那回到最开始的问题：请用动画演示一个 3×3 上三角矩阵交换两行后的变号过程，从行号排列 123 变成 213 的逆序数讲起。”为让真实生成稳定收敛，允许在同一条学生消息末尾追加具体执行约束：“请直接生成动画，并使用具体矩阵 A=[[1,2,3],[0,1,4],[0,0,1]]，动画本体严格不超过 12 秒，不要先反问。”系统自主调用 `render_manim_animation`；录下“生成数学动画”活动卡（scene_code 在 SSE 层已剥离，黑盒为产品原生行为）与动画卡片嵌入助手消息的瞬间。

**必须走真实 `render_manim_animation` 链路**（`GeneratedScene(Scene)` 合约），不用其他软件仿制；黑盒展示（输入 → 输出），不露生成代码。

**硬性验收**：数学骨架 `123 → 213 → τ=1 → 3×3 换行 → det 变号` 五步缺一不可，且必须使用上面的真实对话请求自然约束生成。数学骨架优先于配色、运镜和排版；视觉细节以真实生成结果为准。

**时长口径（v7 当前口径）**：动画本体不超过 12 秒（prompt 合约“画面不超过 12 秒”）；1:12-1:30 段落 = 首帧原问题卡 + ≤12 秒动画 + 结尾结论帧停留（“所以：交换两行，行列式变号。”）。

**媒体参数口径**：分辨率和帧率不是真实性门槛。用 `ffprobe` 记录真实 `width`、`height`、`r_frame_rate` 和时长；只有本体时长参与内容验收。成片导出前统一转码为 1920×1080、30fps，转码不得改变动画内容。

- 状态机口径（`app/services/learning/projection.py`，确定性）：无证据 → 未探索；闭合证据 <2 → 学习中；最近两次闭合连续 independent → 已学过；最近一次闭合为 direct_taught → 需要巩固；近 5 次闭合中 assisted / direct_taught 过半 → 需要巩固；其余 → 基本学过。正式账号以 §3.0 的单次 `independent` 作为前态，录制中再形成讲授 `direct_taught` + 答对 `independent`，预期落 `基本学过`；模型上报仍有随机性，以正式实测为准。
- 前后态必须来自正式账号同一条因果链的产品原生状态，不后期替换标签。若真实后态与预期不同，按实测状态呈现并同步修改旁白，不伪造状态。
- 可选择展示正式账号证据条数的真实变化，但成片不写死数字；所有计数必须由本条真实交互产生，不后期伪造。
- 两节点整章全景相距 1715px（视口 1019px），一屏放不下——相关镜头一律分屏分拍，不拼假同屏。

### 3.7 连续性段（1:50-2:15）

**三个真实镜头组接**：

1. 下一次进入同一教材，学习地图亮 2.3 小节梯子：`两行互换行列式反号` 的状态标签显示真实后态 `需要巩固`（承接此前的学习记录，不是重置）；回忆性镜头，3-4 秒即可。
2. 新线程问相近问题（如“两行相同，行列式为什么为零？”——2.3 节相邻性质，同在真实图谱前置链上）；合格回答不得从头重讲逆序数，只能简短确认或直接跳过，把教学重心推进到新性质 / 展开式。
3. 镜头落在系统推进后的真实追问或讲解句上（取真实说出的句子，不补写），让“逆序数已经回补”实际改变下一次的教学起点。
