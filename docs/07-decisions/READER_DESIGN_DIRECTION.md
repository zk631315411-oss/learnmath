# 阅读器设计方向：数字书房

## 一句话定位

把阅读器界面从"网页"还原成"书桌"——用户打开的不是一个管理后台，而是一本摊开的教材和旁边的空白边注纸。

## 设计调性

- **安静**：背景低存在感，让 PDF 纸张和提问内容成为视觉中心。
- **温润**：全部色彩落在暖色光谱，避免冷蓝/冷灰与纸张主题冲突。
- **克制**：减少大色块、粗边框和强阴影；用细线、浅底色、小圆角建立层级。
- **纸质**：PDF 页面要有"纸张"感，侧边栏要像"边注页"，而非悬浮面板。

## 色彩系统

| 用途 | 色值 | 说明 |
|------|------|------|
| 全局背景 | `#eae5d8` | 羊皮纸灰，比当前米色更灰、更安静 |
| 面板背景 | `#f5f1e8` | 比全局背景稍亮，用于侧边栏、工具栏底 |
| 纸张/卡片 | `#fffdf8` | 微暖的白色，不是纯白，减少刺眼感 |
| 强调色 | `#a0522d` | 低饱和赭石（sienna），用于主按钮、聚焦态 |
| 主要文字 | `#4a4339` | 暖黑，用于标题和重要文字 |
| 次要文字 | `#9a9080` | 暖灰，用于说明、placeholder |
| 边框/分隔线 | `#d9d3c4` | 低对比暖灰，只起界定作用 |

## 字体

- **标题/品牌**：`Songti SC`、`STSong`、`Georgia`、`Noto Serif CJK SC`，呼应教材气质。
- **正文/界面**：系统无衬线字体栈，保证可读性和性能。

## 布局原则

1. **PDF 即纸张**
   - 页面居中，宽度不超过阅读舒适区。
   - 使用多层柔和阴影模拟纸张厚度：`0 1px 3px`、`0 8px 24px`、`0 0 0 1px rgba(0,0,0,0.03)`。
   - 避免粗黑边框和夸张圆角；纸张圆角应极小（2–4px）。

2. **工具栏精简**
   - 只保留最高频操作：翻页、页码、缩放、框选。
   - 按钮用圆形或胶囊形，降低"工具感"。
   - "记录"、"地图"等不常驻工具栏，可收进顶部 header 或右键菜单。

3. **侧边栏即边注页**
   - 右侧"本页概要"与主页面形成"翻开的书"左右页关系。
   - 不要让它看起来像弹出的悬浮面板。
   - 空状态用线稿图标，避免彩色填充背景。

4. **输入区收敛**
   - 底部输入区与侧边栏底部融为一体，或像压在书页边缘的便签。
   - 输入框本身用暖白背景 + 细边框，聚焦时边框变赭石色。

## 组件保留说明

- **地图入口**：不删除，从工具栏移至顶部 header 或教材选择器旁，以文字/图标按钮呈现。
- **记录入口**：同理，收进 header 或页面右键菜单。
- **框选按钮**：保留，但改为赭石描边 + 赭石文字，不做大面积填充。
- **登录/注册**：改为圆角小按钮，与 header 融合。

## 避免的设计问题

- 大框框、粗边框、强阴影。
- 冷暖色冲突（如蓝色 Logo、紫色图标）。
- 工具栏堆满小图标。
- 输入区用纯白背景在暖色面板上突兀跳出。
