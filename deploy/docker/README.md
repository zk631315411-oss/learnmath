# Docker Desktop setup package

This package is intentionally separate from LearnMath because Docker Desktop downloads may be unreliable in mainland China and the installer is large.

Double-click `Install-Docker.bat`. Approve the administrator prompt. Docker Desktop may require WSL2 setup, a reboot, or acceptance of its license terms.

After Docker reports ready, extract the LearnMath application package and run `Install-LearnMath.bat`.
